# city-stroll

为常驻本地的城市人群汇总小红书及全网「美食」和「景点」推荐：**本周趋势 + 一直经典**两份排序，附一天内「景点 + 正餐」行程与时间花费。支持北京、上海、广州、深圳、成都、杭州、西安、武汉、南京、重庆 10 城。DeepSeek Harness（DSH）Cordis 插件，零运行时依赖（只用 `ctx.web` / `ctx.tools` 注入能力）。

## ✨ 功能

- **两份榜单**：近期热门（随季节 / 活动出圈）+ 经典口碑（老牌长青），景点与美食分开呈现。
- **多因子口碑聚合**：交叉验证置信度 × 发布时间衰减 × 热度 × 互动量 × 被提及频次。
- **个性化维度**：
  - 偏好（preference）：综合 / 自然秋景 / 人文老城 / 文艺展览 / 美食探店 / 运动户外
  - 主题（theme）：通用 / 情侣约会 / 朋友聚会 / 亲子遛娃 / 带父母 / 独自慢游（带父母、亲子遛娃会自动剔除登山、攀岩等体力消耗大的去处）
  - 时段（slot）：上午 / 下午 / 晚上（晚上 = 夜游·灯光秀·演艺·夜市，18:00 出发并筛掉爬山、赏红叶等白天专属项）
- **行程规划**：按出发地就近推荐，景点按「真实坐标 + 最近邻顺路」排序减少折返，自动附带地铁通勤路线与时长（基于内置城市 POI 坐标库 + haversine 距离粗算，非实时导航）。
- **苏格拉底式追问**：当出发地 / 出游时长 / 偏好等关键信息缺失时，先向用户逐一确认（一次一个问题）再生成计划。

## 📦 安装

在 DSH 中以 bundle 形式安装。发布到 npm 后：

```text
install_bundle  city-stroll
```

本地开发（从路径）安装：

```text
install_bundle  C:\path\to\city-stroll
```

启用 / 停用（无需重启）：

```text
set_bundle  city-stroll  enabled:true
```

## 🚀 使用

安装后即可通过 `xiaohongshu_guide` 工具调用：

| 参数 | 必填 | 取值 | 说明 |
| --- | --- | --- | --- |
| `destination` | ✅ | 字符串 | 目的地或区域，例如「上海」「杭州西湖」「北京海淀」「成都」。 |
| `scope` | | `both` / `attractions` / `food` | 查询类别，默认 `both`。 |
| `duration` | | `半天` / `全天` | 出游时长，默认 `半天`。 |
| `origin` | | 字符串 | 出发地 / 地铁站，默认 = 该城市中心地铁站（如北京知春路 / 上海人民广场）。 |
| `preference` | | 综合 / 自然秋景 / 人文老城 / 文艺展览 / 美食探店 / 运动户外 | 偏好风格，默认 `综合`。 |
| `theme` | | 通用 / 情侣约会 / 朋友聚会 / 亲子遛娃 / 带父母 / 独自慢游 | 同行人 / 场景，默认 `通用`。 |
| `slot` | | 上午 / 下午 / 晚上 | 出游时段，默认 `上午`。 |

## ⚙️ 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `maxResults` | `8` | 每个检索桶返回的最大结果数（1–20）。 |
| `timeoutMs` | `120000` | 每次 web 检索超时（10000–600000 ms）。 |
| `defaultOrigin` | `知春路` | 未命中任何城市数据时的兜底出发地。 |

## 🧠 原理简述

1. 按「热门 / 经典」两个桶构造多条定向检索（含 `site:` 限域与榜单词）。
2. 对检索结果做来源域名分类（官方 / 点评 / 社区 / 榜单 / 噪声），计算交叉验证置信度。
3. 用内置 POI 别名表做实体归一化（如「香山公园」=「北京香山公园 / 香山 / 香山红叶节」）。
4. 按偏好 / 主题 / 时段过滤与加权排序，产出两份榜单。
5. 用内置坐标 + haversine + 最近邻贪心生成顺路行程与通勤估算。

## ⚠️ 诚实说明

- 不直接抓取小红书（无官方 API），通过 `ctx.web` 泛搜并在结果中附免责声明。
- 「热度」为基于检索结果、发布时间、互动量与关键词信号的多因子**启发式估算**，非小红书官方实时数据。
- 通勤与顺路为内置坐标 + haversine 的**粗算**，非精确导航，请以高德 / 百度地图为准。
- 无 LLM 事实约束，个别标题可能残留噪声（小红书句子型标题、繁体、微博正文页等）。
